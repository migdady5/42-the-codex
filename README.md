# The Codex

A Python project about elements, alchemy, potions, and transmutation.

## What it covers

- Element definitions and combinations
- Potions and recipe data
- Grimoire-style reusable modules
- Transmutation rules
- Alembic exercises
- Distillation and controlled transformations
- Failure handling through the Kaboom exercises

The project practises modular design, domain rules, and composing small components into an alchemy system.

This activity has been created as part of the 42 curriculum by amigdadi.
